A pre-token protocol radar: it ranks the protocols that have no token yet by an implied value
derived from TVL, seven-day growth and time since listing, and gives each one a farm plan with
its steps, cost and window. The board is the model's claim, never the library's: every row
carries the arithmetic that produced it, and the program re-reads what it wrote and refuses to
hand in a board it cannot stand behind.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
