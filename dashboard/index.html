How the implied value is built

—

  1. Category multiple. The median market-cap-to-TVL ratio of the snapshot's own live-token peers in that category, clamped and shrunk toward a written prior by sample size. A category with fifteen live peers is trusted; one with a single peer falls back to the prior.
  2. Growth and momentum. The seven-day TVL move, clamped to ±50% and damped to 35% of its size, plus a signed-square-root read of the same move so a protocol bleeding deposits is penalised more than a flat one.
  3. Maturity bell. An asymmetric log-normal curve peaking near 300 days of running with no token: the fall-off is gentle below the peak and steep above it, because a protocol that has run for years with no token has had every chance to issue one.
  4. Breadth and dust. Each extra chain adds 4% up to five chains; a protocol under $5M of TVL is scaled down toward 75%.

No protocol name is special-cased: the same function scores every row, and every row's detail view shows its own arithmetic.

—

The implied value is this dashboard's own claim, not make.fun's, and not a prediction that a token is issued. A protocol that records no token may still have one its record does not carry: verify before you commit capital.
